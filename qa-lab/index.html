Fluxo de trabalho

Como funciona o laboratório

Explore

Navegue pela loja fictícia "TechCart" — login, cadastro, busca e carrinho — como se fosse uma release para homologar.

Planeje

Escreva casos de teste no gerenciador: pré-condição, passos, resultado esperado. Use o checklist de referência como ponto de partida.

Execute

Rode cada caso manualmente, carimbe o resultado (passou/falhou) e registre o defeito encontrado no log de bugs.

Evolua

Com a suíte estável, comece a automatizar os casos críticos com Playwright/Cypress e publique um relatório de execução.
